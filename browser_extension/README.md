# 求职助手一键收录扩展

这个本地 Chrome 扩展用于把当前已登录、已打开的小红书、BOSS 或实习僧岗位页面收录到求职助手。

1. 启动求职助手，并打开“岗位发现”。
2. 在 Chrome 地址栏输入 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录 `browser_extension/`。
4. 从求职助手复制配对码，在扩展中保存一次。
5. 正常浏览小红书、BOSS 或实习僧岗位，点击扩展图标，选择“准备投递 / 继续了解 / 暂不投递 / 信息待补全”并收录。

扩展会保存当前可见的岗位正文、结构化信息、发布时间、页面截图和你的初步判断。发布时间只用于发现箱的新鲜度提示，不进入匹配分。

扩展只连接本机 `127.0.0.1:8765`，不会读取平台密码，也不会自动投递、发送消息、点赞或收藏。
